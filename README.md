# SensoryAI-ROS2

This is a development repo of [ROS2_E2E_Visual_Processor](https://github.com/GODCREATOR333/ROS2_E2E_VisualProcessor) aimed to use webrtc instead of websockets to reduce latecny and this is an experiemental repo which works like a test bench to see how different open source computer vision models perform for ROS2 env and see what works best for which application. This repo is currently being used to test [YOLO models](https://docs.ultralytics.com/) , [SAM2 models](https://ai.meta.com/sam2/) for object dectection, classification, segmentation and tracking. Making these models works with minial latency and gpu resources can be a huge plus for ROS2 Application to bring autnomous capabilites at scale. I am further using Nvidia Isaac Sim to test viability ,precision and accuracy in a simulated environment of a simple robot with these models running.
